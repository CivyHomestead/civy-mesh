# CIVY — Off-Grid Community Resource & Task Mesh

CIVY is an open-source, 100% offline-first, decentralized peer-to-peer resource sharing and mesh network. 

## Project Principles
* **100% Offline-First:** Operates without continuous internet or centralized servers.
* **Decentralized:** Uses local-first SQLite storage and peer-to-peer sync via LoRa and Wi-Fi.
* **Subscription-Free Forever:** Open technology designed for community resilience.
* **AGPLv3 Licensed:** Remains open-source and community-owned.

## Repository Architecture
* `apps/mobile/` — React Native (Expo) mobile client for iOS and Android.
* `firmware/pico-node/` — MicroPython drivers and firmware for Raspberry Pi Pico 2 W nodes.
* `shared/types/` — Shared TypeScript interface contracts for CMDB data payloads.
